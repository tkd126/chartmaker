# 초등학생용 데이터 시각화 프로그램

CSV 파일과 공개 구글 스프레드시트를 읽어 막대·선·원형·도넛 차트를 만드는 단일 HTML 웹앱입니다.

## 사용 방법
1. CSV 파일(최대 10MB)을 올리거나 웹에 게시한 구글 스프레드시트를 불러옵니다.
2. 처음 5개 행의 미리보기를 확인합니다.
3. 차트 유형과 X/Y 열을 선택합니다. Y축 기본값은 두 번째 열입니다.
4. 차트 생성 버튼을 누릅니다. 각 차트를 PNG로 저장하거나 개별·전체 삭제할 수 있습니다.

같은 X축 이름은 숫자를 합산합니다. 범주가 10개를 넘으면 합계가 큰 상위 10개만 표시합니다. 원형·도넛의 백분율은 전체 범주 합계 기준이며, 제외한 항목은 빈 각도로 남습니다. 원형·도넛은 항목별 합계에 음수가 없고 전체 합계가 양수여야 합니다.

## 실행과 배포
`index.html`을 브라우저에서 열거나, Vercel에서 Framework Preset을 Other로 선택해 저장소 루트에서 정적 배포합니다. 빌드나 패키지 설치가 필요하지 않습니다.

Tailwind CSS, Chart.js 4.4.8, chartjs-plugin-datalabels 2.2.0, PapaParse 5.4.1을 CDN으로 불러오므로 인터넷 연결이 필요합니다. 구글 시트는 웹 게시와 공개 접근이 필요하며, 접근 정책에 따라 불러오지 못하면 CSV 업로드를 사용할 수 있습니다.

CSV는 브라우저에서만 처리합니다. 구글 시트에는 개인정보가 없는 공개 자료를 사용하세요. 차트는 새로고침하면 사라지므로 필요한 결과는 PNG로 저장하세요.

`example.csv`는 연습용 과일 데이터입니다.
